ACTUALIZACIONES SEGURAS

Importar cambios del proveedor

Compará un archivo JSON o CSV con tus productos existentes. Primero verás una vista previa; no se crea ni publica ningún producto automáticamente.

¿Cómo funcionará?

Guardá o convertí los datos que recibas de GoPartner a la plantilla. El sistema intentará identificar productos por ID del proveedor, clave del catálogo o una combinación única de marca y modelo/nombre. Las coincidencias ambiguas se omiten para que no se actualice el producto equivocado.

Importante: provider_price_usd y provider_price_nio son los precios de referencia del proveedor, no tu comisión ni el precio público. Para cambiar el precio que ve el cliente, el archivo debe incluir expresamente catalog_price_usd o catalog_price_nio.

Las fotografías, la publicación, los productos destacados/exclusivos y el estado de borrador se conservan. Solo se actualizan campos que estén en el archivo y que hayas habilitado abajo.
